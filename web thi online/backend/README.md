# NestJS Backend for Web Thi Online

This folder contains a separate NestJS backend server for the Web Thi Online project.

## Quick start

```bash
cd "d:\Web_thi_truc_tuyen\web thi online"
pnpm install
pnpm --filter @web-thi-online/backend dev
```
